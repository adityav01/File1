eSSL export tips

  • From eTimeTrackLite: Reports → Transaction / Punch log → Export Excel or CSV.
  • User ID in the file must match the number stored on the biometric device.
  • If Date and Time are separate columns, both are combined automatically.
  • Re-importing the same punch (same person, time, device) is skipped.
